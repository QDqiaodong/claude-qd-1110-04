# 画室 · 学员档案与画材库存

画室业务管理系统：以「学员档案」为主，串起课程排期与画材领用两条从线，画材独立台账。靛青主题、顶部标签页导航、学员列表双击行打开右侧抽屉查看档案与排课。

## 启停

```bash
sh start.sh     # 构建并启动（mysql / backend / frontend）
sh stop.sh      # 停止
sh clean.sh     # 停止并清理数据卷
```

## 验收

课后成果记录闭环：

```bash
sh start.sh
node acceptance/acceptance.mjs    # 覆盖正常提交/取消课次/重复提交/并发提交/学员删除与状态变化
```

排课 / 取消状态闭环：

```bash
sh start.sh
node acceptance/schedule-acceptance.mjs
# 覆盖：取消后原时段立即重排、边界相邻时段、重复取消幂等、并发取消与排课（无双占）、
#       已上课不可取消、取消记录保留供历史查看、列表/档案抽屉/刷新状态一致
```

画材消耗看板：

```bash
sh start.sh
node acceptance/material-board-acceptance.mjs
# 覆盖：空范围、跨月月末边界、材料与学员交叉筛选、归还后的净消耗与库存变化、
#       删除学员后的原姓名快照、连续切换筛选时结果只对应最新条件
```

## 模块

- 学员档案：学号唯一、手机号校验、级别（少儿/成人/艺考）、状态（在读/休学/结业）；有排课/记录时删除被拦截；仅有画材领用记录可删除，领用表保留原姓名快照
- 画材库存：名称唯一、库存≥0、类别（颜料/画笔/画布/工具）、停用不可领用；库存页提供画材消耗看板，可按本地日期范围、材料、学员查看领用/归还/净消耗/当前余量，并展开同一口径明细
- 课程排期：依赖学员（在读才能排课）、同日期时段不重叠（已取消不占时段，相邻时段可排）；
  待上课可取消/签到；取消后原日期时段立即释放可重排，取消记录保留供历史查看（不再参与重叠校验）；
  已上课为终态不可取消；排课/取消/签到经学员行锁串行，并发按最终状态裁决（幂等取消、无双占）
- 领用记录：新建领用即扣库存、画材须「在库」、库存不足拦截；按原领用记录部分或全部归还并回补库存，不能超额归还；看板与列表共用同一服务口径
- 课后成果记录：仅「已上课」课次可建；一课次一份（课次行锁 + schedule_id 唯一索引 + 幂等提交）；
  草稿（可只填点评）→ 已提交（作品主题/完成度/点评必填）→ 已归档（只读）；
  草稿不计入已完成课程；课程详情与学员档案均展示记录当前状态与最后更新时间；
  删除草稿只删记录行，不触碰课次、库存与学员状态
